# Instruções para o beta fechado — v0.27.0

1. Hospede o projeto em HTTPS.
2. Abra o jogo e acesse **Beta** pelo menu lateral.
3. Execute **Auditoria interna**.
4. Teste os fluxos do checklist e marque somente o que foi confirmado.
5. Marque o aparelho/navegador efetivamente testado.
6. Em caso de falha, use **Relatar problema** e exporte o JSON.
7. Envie o JSON ao responsável pelo projeto pelo canal combinado fora do jogo.

A telemetria local é opcional, inicia desativada e não envia dados. O arquivo só sai do aparelho quando o testador escolhe exportá-lo e compartilhá-lo.
