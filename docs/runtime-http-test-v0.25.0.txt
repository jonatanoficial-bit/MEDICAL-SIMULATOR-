Medical Simulator v0.25.0 — nota de teste de runtime

A política administrativa do ambiente bloqueou navegação Chromium direta por localhost/file em fases anteriores. Nesta fase, o runtime JavaScript, carregamento externo, save, service worker e integração foram auditados separadamente; o DOM de produção, CSS real, i18n e gestos foram inspecionados em Chromium isolado.

Pendências para aparelho físico HTTPS:
- instalação PWA;
- atualização offline;
- tela cheia real;
- TalkBack/VoiceOver;
- desempenho prolongado;
- validação do gesto em Chrome Android, Samsung Internet e Safari iOS.
