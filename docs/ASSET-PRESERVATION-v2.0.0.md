# Preservação dos ativos visuais — v2.0.0

Os avatares, fundos, ícones e imagens da versão original foram copiados sem recompressão, conversão ou edição. A validação final compara caminho relativo, quantidade e SHA-256 de cada arquivo visual entre a origem preservada e a edição 2.0.0.

Inventário esperado: 31 arquivos visuais. O relatório JSON final contém o resultado detalhado da comparação.
