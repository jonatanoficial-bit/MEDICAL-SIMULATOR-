# Build Report — v0.21.0

Fase: Exames, Medicamentos e Procedimentos Avançados.

## Implementado

- Ciclo de pedidos diagnósticos com tempo de processamento.

## Segurança

Todo conteúdo permanece development-only e não substitui prescrição, decisão clínica ou treinamento supervisionado. A publicação comercial continua bloqueada até validação médica, farmacêutica, terminológica e de segurança independente.
